## 3. §2 新功能 = 新風險（請用敵對心態打）

算式同全角係今次**新加**嘅解析能力，請當佢係新攻擊面：

1. **注入**：`alert(1)`、`1;2`、`process`、`__proto__`、`constructor`、`1,2`、反引號、`${1+1}`
   —— 期望全部**拒絕**（實作係自己寫嘅解析器，冇用 eval；請幫我驗證呢點）
2. **數值邊界**：`999999999*999999999`、`0.0000001`、`1/3`（無限小數）、`-0`、`1e9+1`
3. **括號**：`((40))`、`(40`、`40)`、`()`、`(((1+2)*3)/4)`
4. **混搭**：`1/2+1/4`（inch 模式 — 分數同算式撞）、`10mm+5`、`１０＋５`（全角算式）
5. **分數唔准被搶走**：inch 模式 `1/2` 一定仲係「半吋」，`1 1/2` = 1.5 吋，
   `1-1/2` = 1.5 吋（**唔可以**當成 1 減 0.5）
6. **來回一致**：入完算式之後，欄位顯示嘅數字再讀返要係同一個值（打 `10+5` 之後
   欄應該顯示 `15`，唔係仍然顯示 `10+5` 或者變返舊值）
