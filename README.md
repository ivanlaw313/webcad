# WebCAD（代号）— 浏览器里的 Fusion-360 式参数化 3D CAD

一个**网页 + 桌面双端**的参数化实体建模器，操作方式高度对齐 Autodesk Fusion 360。
几何由真正的 **OpenCASCADE (OCCT) B-rep 内核**（C++ 编译成 WebAssembly）在 Web Worker 里计算——和 Fusion 一样是精确实体，不是网格近似。重点是 **实体建模 (SOLID) + 装配 (ASSEMBLY)**。

> 干净重写（clean-room）的"受 Fusion 启发"工具，**没有**反编译或抄用 Autodesk 的任何代码 / 图标。所有面向用户文字为中文（粤）。

- **线上（生产）**：https://cad.neuralworkshk.com
- 工具入口卡：https://neuralworkshk.com/tools/zh-hant/
- 详细交接 / 完整功能规格见 **`HANDOFF.md`**；逐条变更历史见 **`DEVLOG.md`**。

## 快速开始

```bash
pnpm install
pnpm dev            # 网页开发（热更新）→ http://localhost:5173
pnpm build          # 生产构建（含 tsc 严格检查）→ dist/
# 桌面（Windows，需 MSVC 生成工具；先 source vcvars64.bat）
pnpm tauri build --no-bundle   # → src-tauri/target/release/app.exe
```

## 已实现功能（均已构建 + 功能测试，无"空心"按钮）

**草图**
- 自由草图 + 约束草图（planegcs：重合/水平/竖直/平行/垂直/相等/点在线上/固定 + 距离/半径/角度尺寸驱动 + 完全/欠定义着色 + Trim 修剪）
- 工具：矩形、圆、椭圆、折线、**样条曲线**、正多边形、槽、圆角矩形、三点圆弧
- 草图平面：XY 水平 / XZ·YZ 竖直 / 任意基准高度 / 偏移平面 / **实体平面 / 斜面 / 曲面** 上建草图；可调网格吸附；打数字精确尺寸；H/V/45° 角度推断；闭合轮廓淡蓝填充；尺寸标签可点改；草图镜像 / 阵列 / 倒圆角 / 偏移

**实体造型（CREATE）**
- 拉伸（加料/切割/相交 + 对称 + 扭转角 + 拔模角 + 贯通，实时预览）、旋转（任意角度 + 车槽）
- 多截面放样、沿路径扫掠、螺旋弹簧、管道、加强筋 Rib、**文字凸印/刻字**
- 直接原语：长方体 / 圆柱 / 球 / 圆环 / 圆锥·圆台 / 楔形·斜坡 / 圆顶·半球 / 圆管(衬套) / 棱柱(正多边形)
- 传动件：**渐开线正齿轮 / 齿条 / V带轮 / 真螺纹杆**（真渐开螺旋牙，非贴图）
- 孔：通 / 盲 / 沉头 / 埋头；**M3–M10 标准过孔 + 攻丝底孔**尺寸
- 阵列：矩形 / 环形 / **沿草图路径**；镜像

**实体修改（MODIFY）**
- 按拉 Press/Pull、圆角 / 倒角（**多选棱 + 半径对话框**，失败自动减半径 + 回退可倒棱组）、抽壳（智能顺序提示）
- 曲面贴花（圆柱面凸台/凹槽/锉平面）、拔模、缩放、布尔（并/差/交）、分割实体、移动/复制（含绕 XYZ 旋转）

**装配（ASSEMBLE）★**
- 多组件：新建 / 选择（树 / **3D 点选 / 双击聚焦**）/ 移动 / 旋转 / 隐藏 / 重命名 / 复制 / 镜像 / 删除（可撤销）/ 独立配色 / 自动配色 / 孤立 / 爆炸视图
- 关节 6 类：刚性 / 旋转 / 滑动 / 圆柱 / 球 / 平面，正向运动学 + 限位 + 驱动滑块 + DOF 读数 + ▷运动动画
- **运动连接（齿轮比 / 齿条）**；传动模板自动接好关节联动
- **闭环机构**：四连杆 / 滑块曲柄（活塞），约束求解、杆长刚性保持

**检查 / 分析（INSPECT）**
- 质量属性（尺寸 / 体积 / 表面积 / 质心 / 质量按材质密度）、⊕重心 3D 标记（装配体积加权）
- 测量：两点距离 + ΔXYZ / 量边（长度·孔径Ø）/ 量面（面积·类型）/ 量角（两面夹角）
- 剖视裁剪、**干涉检查 + 最近间隙(clearance)**、选中组件单件属性 + 📏到最近邻件间隙 + **📐量两件中心距/ΔXYZ/间隙**

**出图 / 导入导出**
- 工程图：三视图 + 立体图 + **剖视图(前向半剖)** + 标题栏 → SVG
- **BOM 材料清单**（各零件 数量/体积/质量 + 合计）→ CSV
- 导入 STL / STEP(真实 B-rep)；导出 STL / **单件 STL** / **全部零件打包 zip** / STEP / 装配 STL / glTF(含色) / 草图 DXF / **钣金展开 DXF**(激光下料) / **PNG 截图**(3D 视图)
- 保存 / 打开（`.json`，完整保留特征+组件+关节+运动连接+材质）+ **自动保存防丢失**（localStorage）

**参数化**
- 命名参数表 + 表达式（引用其它参数/链式）；特征尺寸绑定参数，改一处全联动
- 时间轴：点节点回放到该步 + 改参数自动重建 + 重排序 + 多参数编辑 + 历史回放

**钣金（SHEET METAL）**：截面折弯 L/U/Z + K 因子展开 → 展开 DXF

**材质库**：钢 / 铝 / 黄铜 / 铜 / 钛 / 金 / 银 / 不锈钢 / 青铜 / 玻璃(透明) / 塑料 / 黑塑 / 喷漆 / 橡胶 / 木（含密度 → 真实质量/BOM）

**显示单位**：mm / cm / inch 切换（影响所有屏幕读数；STL/STEP/DXF 等制造导出仍用 mm）。

**界面 / 交互**：7 个 workspace tab + 左侧浏览器树（**多选组件批量隐藏/显示/删除**）+ 底部时间轴；鼠标滚轮向光标缩放 / 左键环绕 / 中右键平移 / **右键 marking 菜单** / hover 高亮；起始**示例模板 21 种**（底板/外壳/法兰/L角铁/六角螺母/阶梯轴/垫圈/螺栓法兰/齿轮/钣金支架/齿轮组/螺栓/内齿圈/滚珠轴承/齿轮齿条/行星齿轮组/联轴器/六角间隔柱/NEMA17电机安装板/法兰轴套/通风板）；`/` 命令搜索（支持**日常词同义词**：螺丝→孔、盒→长方体、弹簧→螺旋…）。

## 路线图 / 已知限制（诚实记录）

Fusion solid + 装配核心功能已基本完整。**近期已补**：PNG 截图（gl 工厂 + 空白守卫）· 量两件距离 · mm/cm/inch 单位 · 多选组件批量 · 全部零件 zip · 工程图剖视图 · 命令搜索同义词。剩余偏专业 / 受内核或框架限制的方向（详见 `HANDOFF.md` §8）：
- **曲面（圆柱/球面）上草图**：需 UV 参数化（窄版「曲面贴花」凸台/凹槽/锉平面已可用）
- **多件装配工程图**：需 mesh 轮廓投影（单件工程图 + 剖视已有）
- **行星齿轮动画**：复合自转+公转，单轴运动连接表达不到（静态示意布局）
- **正交/透视相机切换**：R3F 动态换相机类型脆弱（暂以透视 + X-ray 透视代替）

## 技术栈

| 层 | 选型 |
|---|---|
| 几何内核 | OpenCASCADE (OCCT) → WASM，经 `replicad` 封装；Web Worker（Comlink） |
| 2D 约束 | planegcs（FreeCAD 求解器 WASM） |
| 渲染 | Three.js + @react-three/fiber + @react-three/drei |
| 界面 | React 19 + TypeScript + Zustand |
| 桌面 | Tauri 2（Rust 外壳 + 同一套前端） |
| 构建 | Vite 8 |
