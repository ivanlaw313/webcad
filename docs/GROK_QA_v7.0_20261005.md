## 1. 你上一輪揭咗一個我設計上嘅洞

你報嘅 **529 / 533 / 537 / 538 / 541 / 542** 六條係同一個病。我喺本機完整重現：
FORM Box 打 `1e9+1` → 確定掣**真係**灰、紅字**真係**出，但撳 Enter 照樣建件。

根因兩層：
1. `App.tsx` 有個**全域 Enter 捷徑**直接 call `commitFormBoxDraft()`，完全繞過對話框個閘
2. 我設計上「非法就唔寫入 model」（啱嘅），所以 model 仲係**上一個合法值** —— 提交就靜靜用咗佢

**教訓**：正確性唔可以淨係放喺 UI 閘；只要有第二條入口（鍵盤捷徑、程式、AI 助手），UI 閘就形同虛設。
而且上一輪我逐個對話框手接，**漏咗一半**（圓角／孔／拔模／拉伸全部冇接）。

所以 v2.19 改成結構性做法：**欄自己登記「我而家非法」→ 掣、Enter、commit 三邊查同一個真相**。
新加對話框唔會再漏接。
