# 氣動／水動設計：點用

呢份教學畀用慣 Fusion 360、唔使寫程式嘅人。WebCAD 而家可以用三層工具設計風扇、機翼同流線外殼：先快手排名，再比較形狀，最後先用本機流體計算確認。

畫面用語跟軟件本身。下面每一個「」都係你會見到嘅掣或者欄位。

想喺軟件入面睇精簡版：按 **F1**，或者頂欄按 **/** 搜「氣動」「CFD」「風洞教學」「aero guide」，揀「氣動／水動設計教學」。

---

## 三層工具點分

三層唔係三個一樣準嘅計數機。愈下面愈接近真風洞，亦愈耐。

| | ① 工程估算 | ② 瀏覽器風洞 | ③ 本機 OpenFOAM |
| --- | --- | --- | --- |
| 喺邊 | 氣動設計實驗室，撳「▶ 開始優化」 | 結果表嘅「精確模式（LBM）」，或者「風洞水洞」撳「運行」 | 實驗室下面「OpenFOAM CFD 驗證」，或者風洞面板「用 OpenFOAM 驗證呢個形狀」 |
| 幾準 | 用嚟排名。阻力、效率呢類數多數**偏低大約三成**，要第③層嘅校準先至接近真數。唔係 CFD。 | **趨勢級**。同一個設定下，邊個形狀阻力細啲，個排名可信。絕對風阻係數 Cd 唔好當實驗室報告。 | 三層入面最準。球體驗證：Cd **0.490**，參考大約 **0.47**（差幾個百分點）。螺旋槳／風扇呢種轉緊嘅葉**未驗證**。 |
| 幾耐 | 畫面會寫幾多**毫秒**。評估 1200 次通常幾秒內完成。揀 300 次更快；8000 次仍然係秒級。 | CPU：精細度 24 大約幾十秒，拉到 48 可以幾分鐘（大件更慢）。GPU：可以拖住零件即時睇，但 Cd **大約高 2 倍**。 | 粗網格大約幾分鐘到十分鐘（球體嗰套驗證大約 10 分鐘）。細網格或者難嘅形狀可以去到幾十分鐘。**一次只計一個**，其他排隊。 |
| 幾時用 | 掃好多個尺寸，篩走明顯差嘅，留頭幾個。 | 兩個外形邊個順、邊個朝向阻力細啲，想睇煙流。 | 最後一兩個候選，或者你自己畫好嘅一件，要一個認真啲嘅 Cd／阻力。 |

口訣：估算揀人，風洞睇形，OpenFOAM 先至落訂。

## 先打開實驗室

1. 頂部工作區撳 **🧪實驗室**。
2. 喺 **仿真** 一組撳 **氣動設計實驗室**。
3. 右側彈出「氣動設計實驗室」。上面橙色字講明：裡面嘅數係估算，唔係 CFD。

唔想搵掣：按 **/**，打「氣動」，揀「氣動設計實驗室」。

個面板由上到下四步：① 設計需求、② 設計空間、③ 自動優化、④ 結果。

## a) 用範本設計 120mm 靜音風扇

範本已經填好「直徑 120 mm、轉速 2500 rpm、空氣、靜止嚟風」。目標係效率愈高愈好，同時噪音指標愈低愈好。推力至少 0.08 N，失速比例不可超過 0.3。

1. 喺 ① 撳 **🌀 螺旋槳／風扇**。個掣會變色，標題變成「120mm 靜音風扇 / 螺旋槳」。
2. 睇 ②。固定條件：直徑 120、轉速 2500、來流速度 0、流體 **air 空氣**。可變參數係一對最小→最大（葉片數、螺距、弦長、扭角、彎度、厚度），預設範圍可以唔改。
3. 目標應該係兩個：「效率（η 或 FM）· 越大越好」同「噪音指標（相對）· 越細越好」。因為來流係 0，效率呢度係風扇品質因數，唔係飛機螺旋槳嗰種推進效率。
4. ③「評估次數」留 **1200**（想快先改 300）。「隨機種子」留 42 就得；同一個種子會出同一組結果。
5. 撳 **▶ 開始優化**。進度條行完，下面會寫幾多 ms。想中途停就撳 **■ 停止**。
6. ④ 結果表：
   - 「起始設計」係未優化嗰行，用嚟對比。
   - 有 **★** 係折衷之後仍然唔差嘅設計（兩個目標冇單一冠軍）。
   - 行變淡、有 **⚠** 就係未符合約束，唔好當最佳。
   - 撳一行，左邊出現 ▶，下面先係而家揀緊嗰個。
7. 睇「效率」同「噪音指標」。效率高、噪音低就係你要嘅靜音風扇。下面亦會寫比起始設計好咗幾多個百分點。

兩個目標時，中間係一張帕累托圖，每一點係一個可行設計。一個目標先會變收斂曲線。

## b) 用一句說話設計滑翔機翼

唔使自己填翼展。用內置規則就夠，唔使設定 AI。

1. 打開氣動設計實驗室（同上）。
2. 喺文字格貼上呢句（同提示字例子一樣）：

   滑翔機翼 1.2m 翼展 最高升阻比

3. 撳 **按規則生成設計空間**。
   - 如果右下角 AI 助手 ✦ 已經填咗你自己嘅 key，個掣會變成 **✦ AI 生成設計空間**。撳邊個都得。AI 答唔到會自動改返規則，畫面會講。
4. ② 標題會變成機翼、翼展大約 **1200 mm**（1.2 米）。流體係空氣。目標變成「升阻比 L/D · 越大越好」（一句說話只要求升阻比，所以唔再同時追重量）。
5. 來流速度預設 **10 m/s**，重量預設 **0.6 kg**。呢兩個係固定條件，可以改數字。升力會按呢個重量去配。
6. 撳 **▶ 開始優化**。
7. 結果表第一個符合約束、有 ★ 嘅，通常就係升阻比最高嗰個。數值欄「升阻比 L/D」愈大愈好。⚠ 行唔好揀。

機翼插入之後：翼展左右張開，弦長沿前後，風由前方（+X）吹過去。

## c) 設計最低水阻嘅水底推進器外殼

呢個係外殼外形，唔係轉緊嘅葉。用一句說話：

1. 文字格輸入：

   水底推進器 殼要最低水阻

2. 撳 **按規則生成設計空間**（有 AI key 就撳 AI 那個）。
3. ② 應該變成流線殼。確認 **流體** 係 **water 水**，來流速度大約 **2 m/s**（句子冇寫速度，水下預設 2）。目標係「阻力 N · 越細越好」。
4. 約束「容積 L ≥ 1.5」：殼入面至少大約 1.5 公升。你要裝更大嘅機，就改大呢個數。
5. 可變參數：長度、直徑、最粗位置、頭形、尾形、尾端直徑比。頭形 1 尖、3 鈍；尾形 1 係尖錐、3 係飽滿。預設範圍可以唔改。
6. 撳 **▶ 開始優化**。
7. 揀阻力最低、而且有 ✓「符合約束」嗰行。容積唔夠 1.5 L 嘅會變 ⚠。

想直接用現成範本、唔打字：撳 **🐟 流線外殼**。標題係「水底推進器殼 — 最低水阻」，同樣係水、2 m/s、容積至少 1.5 L、阻力愈細愈好。

外殼插入之後係一嚿**實心**旋轉體（鼻尖喺原點，身長沿 X）。「壁厚」只係用嚟估重量，唔會挖空。想做空心，插入之後再用普通 **抽殼**。

## d) 插入模型、用正常 CAD 改、匯出 STL

1. 喺結果表撳你要嗰一行（▶）。
2. 可先撳 **👁 3D 預覽** 睇個形，再撳一次收起。
3. 撳 **＋ 插入模型**。第一次要載入內核，等幾秒。成功會話：已插入為時間軸「STEP實體」。
4. 撳面板右上角 **✕** 收起實驗室。
5. 而家同 Fusion 一樣改：
   - **圓角**、**倒角**、**抽殼**、**孔**、**合併/切割** 都喺實體工具列。
   - 底部時間軸可以返轉頭改上一步。
   - 如果畫面已經有另一件實體，插入會先收起舊件再加新件，唔會靜靜雞覆蓋。
6. 匯出去打印或者交俾人：
   - 左上角 **檔案 ▾** → **匯出 STL**。
   - 想帶返 Fusion 360 繼續改，改撳 **匯出 STEP**。

實驗室結果下面亦有 **⬇ 下載 STL**。嗰個係未插入、未再改過嘅候選外形，方便快手攞檔。改完先要嘅，用檔案選單嗰個匯出。

風扇：轉軸向上（Z），推力向上。機翼同外殼：來流沿 +X。

## e) 送頭幾個去 CFD 驗證、睇校準系數

CFD 就係第③層。做之前：

1. 喺你部電腦雙擊

   `C:\ClaudeCode\aero-cfd-service\start-service.bat`

   黑色視窗留住，唔好關。關咗服務就停。
2. 用 Chrome 開 WebCAD。如果之後話瀏覽器擋咗本機網絡，睇下面「常見問題」。

然後：

1. 優化完成，捲去結果下面 **🧮 OpenFOAM CFD 驗證**。
2. 撳 **檢查服務**。綠色「CFD 服務在線」先好送。位址預設係本機 `127.0.0.1` 端口 `8765`，一般唔使改。
3. **N** 填你要送幾多個。佢送嘅係結果表由上數、有 ✓ 嘅頭 N 個，**唔係**你用滑鼠點咗嗰一行。想快就 N 填 **1**（通常就係表上第一個較好嘅）。最多 8 個。
4. **網格** 第一次用 **coarse**（快）。確認值得再算先改 medium 或 fine。
5. 機翼同外殼有 **求解設定**。留 **自動（Re<3e5 → 層流瞬態）** 就得：低速鈍體用驗證過球體嗰套；較高雷諾數改用穩態。螺旋槳冇呢格，因為佢用另一套轉子算法。
6. 撳 **🧮 送去 CFD 驗證**。
7. 「CFD 工作」會由排隊中 → 計算中 → 完成。有進度、已用時間，計緊時可以見到即時 Cd。一次只跑一個，其餘排隊。唔想等就撳 **取消**。
8. 完成之後張表三欄：
   - **工程估算**：實驗室個數。
   - **OpenFOAM**：呢次計算。
   - **比例 CFD/估算**：OpenFOAM 除以估算。例如 ×1.40，即係估算大約只得 CFD 嘅七成，**少咗大約三成**。
9. 下面 **校準系數（CFD ÷ 估算，按模板）** 會記住呢個倍數（同一個範本做多次會取平均）。未有工作完成之前呢度係空。
10. 剔 **用 CFD／校準值重新排序**。已經算完 CFD 嘅用 CFD 個數；未算嘅用「估算 × 校準系數」。阻力類愈細愈好，效率類愈大愈好。

服務未開或者瀏覽器擋住時，紅色提示下面有 **⬇ 下載案例 ZIP**，可以先存檔，服務開咗再算。唔使自己改檔案內容。

螺旋槳送出去會多一行黃字「未驗證」。個比例可以睇，唔好當成真實推力校正。見下面限制。

## f) 用風洞試自己畫嘅模型，再用 OpenFOAM 驗證

呢步唔經設計實驗室。任何你畫嘅實體、或者插入之後再改過嘅件，都可以。

1. 畫好或者打開一個實體（例如草圖拉伸）。畫面要有件嘢；空場景會話「需要先有活動實體或選中網格件」。
2. **🧪實驗室** → **仿真** → **風洞水洞**。
3. 彈出「風洞 / 水洞（LBM 體素趨勢）」：
   - **流體**：空氣（風阻）或水（水阻）。水底件記得揀水。
   - **速度**：拖桿。10 m/s 大約 36 km/h。
   - **吹向**：自動（最長軸）通常得。方向反咗就撳 **+向／−向**。
   - **精細度**：先留中間。愈右愈慢。
   - **引擎**：留 **CPU（準·可比舊數）**。GPU 只係用嚟拖住睇，Cd 唔準，見限制。
4. 撳 **運行**。等進度條。完成後睇「風阻係數 Cd」同「阻力」。下面細字寫明係趨勢級：相對比較可信，絕對 Cd 偏趨勢。
5. 同一個面板底有 **🧮 用 OpenFOAM 驗證呢個形狀**。撳之前確認 start-service.bat 開住，而且檢查過服務在線（如果未開，個掣會講服務未開或者瀏覽器擋住）。
6. 個掣旁邊會寫 LBM 嘅 Cd。工作跑完，下面用 OpenFOAM 嘅 Cd 對住呢個 LBM 數。兩個數唔同係正常嘅，見常見問題。

風洞係趨勢；OpenFOAM 先至係你要留低嘅數。GPU 引擎嘅 Cd 唔好同 OpenFOAM 對絕對值。

## 已知限制（如實）

- **螺旋槳／風扇嘅 CFD 未驗證。** 本機計算用穩態轉子近似，未同實測螺旋槳數據對過。面板會標「未驗證」。只可以睇邊個推力大致大啲，唔好當真實推力、功率或者效率。
- **瀏覽器風洞嘅絕對 Cd 有偏差。** 佢係格子法趨勢。同一速度、同一流體、同一引擎下，比較兩個形狀先有意思。唔好將 Cd 直接寫進報告當風洞實測。
- **工程估算偏低大約三成，要校正。** 實驗室個阻力／效率係公式快算，多數少咗大約三成。用第③層出嚟嘅「校準系數」（CFD ÷ 估算）乘返估算，先至好拿去排名。未做過 CFD 之前，個估算只係篩選用。
- **GPU 風洞 Cd 大約高 2 倍。** 實測球體係參考值嘅 2.0–2.2 倍，而且幾個精細度都係咁，唔係網格太粗。所以引擎預設 CPU。GPU 只賣「邊個朝向細幾多百分比」同拖曳睇流場。絕對 Cd、絕對阻力用 CPU 或者 OpenFOAM。
- 估算同風洞都唔係商用認證。OpenFOAM 球體先驗證到大約幾個百分點；機翼阻力仍然可以偏高，要睇工作上嘅警告（未收斂、網格警告）。
- 外殼 CAD 係實心外形。壁厚唔等於殼厚。
- 服務一次計一個。細網格會好耐，唔好一次送滿 8 個 fine。

## 常見問題

### CFD 服務未開

紅色字「本機 CFD 服務未開」。雙擊 `C:\ClaudeCode\aero-cfd-service\start-service.bat`，等黑色視窗留低，返去撳 **檢查服務**，見到綠色「CFD 服務在線」。視窗一關，服務就停。仍然未開就先 **下載案例 ZIP**，遲啲再算。

### 瀏覽器擋本機網絡

網站喺網上、計算喺你部電腦，Chrome 會問「本機網絡存取」。如果拒過，會話瀏覽器擋咗，而服務其實可能開住。

撳網址列**左邊**嘅鎖頭或者設定圖示 → **網站設定** → **本機網絡存取** 改做 **允許** → 重新整理頁面 → 再撳 **檢查服務**。

### 計太耐

- 估算應該係秒級。如果評估次數係 8000 又好多個目標，等十秒內仍正常；超過一分鐘先算異常，可以 **■ 停止** 再改 1200。
- 風洞 CPU 拉到最細精細度，大件可以幾分鐘。先用中間精細度睇趨勢。
- OpenFOAM 粗網格都係分鐘級，細網格更耐，而且要排隊。第一次 N 填 1、網格 coarse。進度條有動、已用時間有加，就係計緊，唔好當死咗。唔等就 **取消**。

### 點解同估算唔同

三層用三種方法，數字本來就唔應一樣。

- 估算快，而且多數**低大約三成**。
- 風洞係趨勢，絕對 Cd 會偏；GPU 更會高大約兩倍。
- OpenFOAM 先接近參考（球體 0.490 對 0.47）。

睇「比例 CFD/估算」。機翼同外殼可以用呢個倍數做校準再排序。螺旋槳兩邊都未驗證到可以落報告，只可比較邊個設計大致好啲。工作如果寫「未收斂」，個 CFD 數都要打折扣。
