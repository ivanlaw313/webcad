### 2.1 BUG-406［P0］閂晒分頁，工作要救得返

**根因**（已查明）：自動存檔正常情況下**只寫 `sessionStorage`**，而 `sessionStorage` 嘅壽命等於「分頁瀏覽 session」。閂晒分頁連 tab id 一齊消失 → 新分頁抽一個新 id → 三條讀取路（sessionStorage / tab-scoped localStorage / 舊共用鍵）全部 miss → 存檔變成永遠搵唔到嘅孤兒。

> ⚠ 呢個係「修 A 製造 B」：tab 隔離本來係為咗修 BUG-276（新分頁偷咗舊分頁文件，你上輪確認 FIXED）。所以修法**冇**改返自動載入。

**改成點**：寫存檔時額外鏡像一份**恢復副本**去 localStorage（帶內容標示）。新分頁搵唔到自己嗰份但有孤兒 → **檔案 ▾ 會多一個橙色「恢復自動存檔（N）」項**，由你明確揀。**唔會自動載入。**

**點重驗**
1. 純網址（唔加 `?ui-test`）→ 檔案 ▾ → 新建
2. Box 40×30×20 → 孔 Ø6 貫通 → 雙擊孔改 Ø8 → OK（應該 23.00 cm³）

### 2.5 BUG-401［P2］`?ui-test` 而家真係乾淨開局

**根因**：兩個閘判斷唔同 —— 隔離要 `?ui-test=1`，但暴露測試鈎只要參數存在。所以 `?ui-test` 拎到鈎但拎唔到乾淨開局。**呢個係總經理寫錯上一份任務書**，害你每條線開局都要手動「新建」。

**改成點**：統一成「參數存在即生效」，而且**讀寫兩邊都隔離**（唔會再寫自動存檔污染）。保留 `?ui-test=0` / `=false` / `=no` / `=off` 明示關閉。

**點重驗**：開 `?ui-test` → 建個 Box → 等幾秒 → F5 → **預期唔還原、特徵 0**。（上輪你報呢度會還原。）

## 3. ★ 測試鈎同環境死結解法 ★

### 3.1 `?ui-test`

```
https://cad.neuralworkshk.com/?ui-test
```
曝露 `window.useApp`（Zustand store），而且**跳過自動還原／唔寫自動存檔** → 每次乾淨開局，**唔使再手動「新建」**。

### ★ 使用紀律（授權 + 界線）★

**✅ 准用 `window.useApp`**
- **夾具準備**：載入 STL／還原存檔 —— 即係你環境做唔到嗰啲
- **讀數驗證**：讀精確體積／尺寸／特徵樹，取代靠截圖估

**❌ 唔准用**
- **執行被測試嘅操作本身**。畫草圖、拉伸、改尺寸…… 一律要用 UI 真撳。
  用 store 直接 call action 去「完成」操作，就唔再係測緊個產品。

**📝 記錄**：用咗 `useApp` 做 setup 或讀數嘅行，`limitations` 欄要寫明
「setup 經 useApp（環境攔截檔案選擇器）」／「數值經 useApp 讀取」。

### 3.3 繞過被攔截嘅 STL 匯入（唔需要外部檔案）

```js
function makeBoxSTL(w, d, h) {                    // 回傳 ArrayBuffer（binary STL）
  const v = [[0,0,0],[w,0,0],[w,d,0],[0,d,0],[0,0,h],[w,0,h],[w,d,h],[0,d,h]];
  const f = [[0,2,1],[0,3,2],[4,5,6],[4,6,7],[0,1,5],[0,5,4],
             [1,2,6],[1,6,5],[2,3,7],[2,7,6],[3,0,4],[3,4,7]];
  const buf = new ArrayBuffer(84 + f.length * 50);
  const dv = new DataView(buf);
  dv.setUint32(80, f.length, true);
  let o = 84;
  for (const t of f) {
    o += 12;                                       // 法向留 0，閱讀器自己算
    for (const i of t) { dv.setFloat32(o, v[i][0], true); dv.setFloat32(o+4, v[i][1], true); dv.setFloat32(o+8, v[i][2], true); o += 12; }
    o += 2;
  }
  return buf;
}
window.useApp.setState({ insertMesh: {
  kind: 'stl', buf: makeBoxSTL(40, 30, 20), name: 'test-box.stl',
  unit: 'mm', flipUp: false, place: 'center',
}});
```

→ **之後所有操作一律用 UI。**
